# SubhuTube

**Ad-free YouTube-like video platform**

A clean, modern React + Vite + Tailwind CSS app that looks and feels like YouTube — with **zero ads** from the app itself.

## Features

- Home feed with video grid
- Full video watch page with related videos
- Search
- Responsive sidebar (collapsible)
- Dark theme matching YouTube aesthetics
- YouTube embeds (no app-level ads or tracking)
- Clean, fast, no bloat

## Tech Stack

- React 18
- Vite
- React Router
- Tailwind CSS
- Lucide React icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173)

## Note on Ads

This app contains **no ads, no ad scripts, no trackers**.  
Videos are embedded from YouTube. YouTube itself may still show its own ads inside the player depending on the video and your account — that is outside the control of this app.
